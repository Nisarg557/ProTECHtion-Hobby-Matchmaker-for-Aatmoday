# Aatmoday

## AI-Powered Hobby Club Matchmaker

Aatmoday is a hobby discovery platform designed to help students discover university clubs based on their interests, personality, goals, social preferences, and available time.

## Features

- AI-powered hobby club matching
- Natural-language interest input
- Semantic interest matching
- Personality and social preference matching
- Goal-based matching
- Time-preference matching
- Event-aware recommendations
- Personalized match explanations
- AI-generated icebreakers
- Club details and activities
- Club enrollment system
- Firebase database integration
- Secure backend for Groq AI requests

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase
- Node.js
- Express.js
- Groq API

## Project Structure

The frontend contains the HTML, CSS and JavaScript files for the Aatmoday interface.

The Node.js backend is responsible for securely communicating with the Groq API.
